# Pre-roll 确认规范

## 目的与位置

P6 是与 P1–P10 其他阶段同级的完整生产阶段，位于 P5 最终 Storyboard 与 P7 H3 Prompt 之间，并以强制用户确认作为阶段出口。它先提取整条故事线的核心点，再从已验收 Storyboard 中抽取相关场景元素，重建一个 10 秒以内的连贯短场景脚本，并按既定风格真实生成 Pre-roll，以尽早确认故事表达和制作方向。

Pre-roll 不是挑选一个代表性原分镜直接生成，也不是把多个原分镜视频快速剪在一起。它是基于全片核心点重新设计的微型场景：在一个可理解的短情境中压缩呈现核心人物、核心行动或冲突、关键转折/知识点和整体视觉气质。

Auto 和互动模式都必须执行 P6 并等待用户明确确认。确认前不得创建或运行正式 P7、P8、P9、P10 任务。

## 固定输入

Pre-roll 必须同时追溯到：

1. P2 最终视频脚本与完整故事线；
2. P3 已验收的整体视觉风格、角色和场景资源；
3. P4 与所选情景相关的真实语音和时间线，若该情景包含对白或旁白；
4. P5 完整分镜计划、连续性关系和已验收 Storyboard；
5. 用户此前已经确认的约束与禁用项。

不得为 Pre-roll 新增未经确认的事实、角色、剧情、画面文字、视觉风格或产品表达。

## 核心点提取与场景重建

1. 从完整故事线和 P5 分镜计划中提取必须被 Pre-roll 感知到的核心点：核心人物、叙事目标、关键行动/冲突、知识或情绪转折、结果方向，以及最能代表项目的视觉特征。
2. 从多个已验收 Storyboard 中抽取能支撑这些核心点的特定画格、场景锚点、人物动作、构图、运镜和连续性信息，保存来源分镜 ID、`storySegmentId`、`sceneId` 和资源标识。
3. 将提取内容重新组织成一个连贯的 `Pre-roll 场景脚本`。如果核心点原本分布在多个场景，必须把它们转译成同一短情境中的连续动作或视觉节拍；不得随机跳场、信息堆叠或做无叙事关系的蒙太奇。
4. 从 P3 整体视觉风格和被抽取场景中形成专用 `Pre-roll 风格定义`，明确画幅、光线、色彩、材质、镜头质感、表演和运镜边界；不得创造与全片冲突的新风格。
5. Pre-roll 场景脚本必须包含清晰的开始、推进和落点，控制为一个 3–10 秒整数时长的视频；不得超过 10 秒。

P6 的固定中间产物是：`核心故事点`、`Storyboard 抽取清单`、`Pre-roll 场景脚本`和`Pre-roll 风格定义`。四项都必须进入生成输入快照。

## 快速生成

Pre-roll 只生成重建后的微型场景，不批量生成正式分镜。它组合 `Pre-roll 场景脚本`、`Pre-roll 风格定义`、Storyboard 抽取素材和必要角色/场景/音频 Reference，使用与正式视频相同的目标画幅、H3 模式、角色/场景引用规则和无文字边界。可以生成专用 preview Prompt，但必须标记为 `previewOnly`，不得冒充 P7 正式 Prompt。

Pre-roll 视频必须标记 `previewOnly: true`、`mergeEligible: false`，保存来源输入快照和视频 SHA-256。它不进入 P9 正式验收与 P10 合片；如果其内容后来成为正式分镜，必须在 P7/P8 按当前输入重新生成并通过 P9。

## 用户确认

向用户展示实际 Pre-roll，并附一份简短检查项：

- 故事情景和情绪是否准确；
- 角色、场景和整体视觉风格是否正确；
- 动作、表演、构图和运镜是否符合预期；
- 节奏、音画关系和噪点/质感是否合适；
- 是否存在需要推广到全片的新增调整规范。

只有用户明确确认当前 Pre-roll 后，才记录确认状态、当前视频哈希、输入快照和确认时间，并进入 P7。

## 调整与回流

用户给出调整时，先把要求保存为 `Pre-roll 调整规范` 并标明适用范围：

| 调整类型 | 回流阶段 |
|---|---|
| 事实、故事重点、叙述逻辑、台词 | P2 |
| 角色、服装、场景、光线、颜色、质感、统一风格 | P3 |
| 语气、声音、节拍、音画时间关系 | P4 |
| 镜头拆分、动作、构图、运镜、连续性、Storyboard | P5 |
| 核心点取舍、Storyboard 抽取、微型场景组合方式 | P6 内重建场景脚本 |

属于 P2–P5 的问题必须更新权威上游产物并使旧 Pre-roll 和受影响下游失效；属于 P6 场景重建方式的问题则重新执行核心点提取、Storyboard 抽取或场景脚本重建。两种情况都必须生成新版 Pre-roll 并再次等待确认。不得只修改 Preview Prompt 掩盖场景脚本或上游定义错误。

用户确认后，适用于全片的调整规范必须成为 P7 的显式输入并进入后续 Prompt 和输入快照；仅适用于 Pre-roll 场景重建的要求保留在 P6 记录中。不得仅保留在聊天记录中。
