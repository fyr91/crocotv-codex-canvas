# 三视图固定基础提示词

Create one single character reference sheet containing exactly three orthographic full-body views arranged in one horizontal row. From left to right: complete front view, complete left-side profile view, complete back view. Keep exactly the same character identity, body proportions, clothing, materials, scale, eye line, and ground line in all three views. Show the entire body without cropping. Use a clean neutral background. No extra views, characters, poses, outfits, text, arrows, logos, borders, or watermarks. Treat this as the canonical structural reference for later production.

在此固定结构之后追加本项目的角色形象和风格要求。固定部分不得限制媒介或美术风格。
