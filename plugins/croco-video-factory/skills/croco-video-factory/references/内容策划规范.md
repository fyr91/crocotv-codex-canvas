# P2 内容策划与剧本锁定规范

## 目标与边界

把 P1 简报转化为准确、适龄、视觉先行且经用户确认的最终剧本。最终剧本是 P3–P8 的权威叙事依据。

P2 不确定正式机位、运镜、景深、Storyboard、H3 Prompt 或媒体生成参数。画面文字默认“无”；只有用户明确要求时才保留精确原文。不得自动选择用户未指定的正式角色。

## 固定顺序与 Prompt

1. Gemini 使用 [P2 主题与大纲 System Prompt](P2-主题与大纲-System-Prompt.md)生成主题分析和待核验内容大纲。
2. Codex 使用研究工具按大纲 Claim 定向研究，并按 [Critical Information 审计规则](../../content-optimization-audit/references/critical-information-audit.md)完成 source verification，形成事实依据、Claim/source 映射和逐 Claim Gate 结论；研究与验证动作本身不是 Text 产物。失败返回内容大纲，只重验受影响 Claim。
3. Codex 事实 Gate 通过后，Gemini 使用 [P2 剧本初稿 System Prompt](P2-剧本初稿-System-Prompt.md)生成剧本初稿。
4. GLM 使用 [P2 剧本校定 System Prompt](P2-剧本校定-System-Prompt.md)和 [Humanizer 规则](../../content-optimization-audit/references/humanizer-rules.md)做表达校定与去 AI 化，不重复事实审核。
5. Auto、互动模式都展示完整候选剧本并等待用户确认；确认后锁定哈希与 `approvalSnapshot`。

## 主题分析

至少定义：一句话核心问题、受众认知起点、只解决什么、明确不讲什么、观众只需记住的一句话、候选钩子、候选叙事路线、预期收获和待核验 Claim。钩子必须能在前 3 秒形成可见问题且可由正文兑现。

## 待核验内容大纲

每个连续叙事节拍记录：

- 稳定 `beatId`、知识目的和 `claimIds`；
- 叙事事件、角色功能、可见证据或类比；
- 观众新增理解、情绪/认知变化和前后依赖；
- 临时时间预算。

每个节拍只承担一个主要知识目的。至少一次认知转折来自证据、实验或推理，不靠突然音效和无关笑料。

## 事实依据与 Codex 调研 Gate

每个 Claim 记录：准确主张、来源名称/链接、来源支持的表述、限定条件、适用范围、适龄解释、对应 `beatId`，以及 `supported / revise-outline / remove / user-decision`。

优先权威机构、原始研究、教材和可靠专业资料。惊人数字、纪录、概率、历史第一和因果结论必须有直接来源；不得凭模型记忆补齐。

Codex 在调研过程中直接判断证据是否足够支持主张、推论是否越界、限定条件是否保留，以及来源与结论是否错配。Gate 未通过不得调用 Gemini 写剧本；通过后立即进入剧本初稿。若大纲事实/结构变化，重新研究并通过受影响 Claim 的 Gate；纯措辞变化不重跑事实核验。

## 剧本初稿

先设计可见事件，再匹配旁白和对白，不得先写完整口播再找装饰画面。包含：

1. 标题、一句话承诺、目标用户、核心概念/类比和临时总时长；
2. 角色及其本片功能；
3. 按 `beatId` 排列的脚本节拍表：知识目的、视觉事件/动作、Narration、Dialogue、用户明确要求的画面文字、叙事衔接；
4. 回答开场问题的结尾。

不得新增未通过 Claim，不得改变事实限定、事件因果或大纲顺序。Narration 与 Dialogue 严格分开并标明角色。

## GLM 后置校定

GLM 处理自然度、可说性、角色语言、机械句式、重复解释、空话、套路排比、AI 腔、适龄性和衔接。不得重选主题、重做大纲、新增事实或改变已通过的结构/因果。

若发现初稿偏离大纲/事实，输出 `script-drift` 并要求 Gemini 重生；只有需要改变 Claim/限定条件时才退回事实 Gate。

## 表达与结尾规则

- 一句话只承载一个主要意思；内容过密时拆节拍，不删专业名词和因果条件。
- 专业名词准确出现，并立即用可见现象、生活经验或简短类比解释。
- 6–8 岁具体、适度重复；9–12 岁活泼但不幼态；12–15 岁直接尊重；一般受众自然克制。
- 不用成人网络梗、强行卖萌、居高临下讲课腔或只站着讲解的角色。
- 禁止点赞、关注、转发、评论、购买、订阅等 CTA。
- 不把旁白、对白、关键词或数字自动变成画面文字。

## 用户反馈回流

- 只改措辞且不影响事实/大纲/因果：反馈作为输入重跑 GLM 校定。
- 改主题、知识点、事实、钩子、结构或因果：回到相应大纲条目并重新通过事实 Gate。
- 未重新确认的新剧本不得进入 P3。
