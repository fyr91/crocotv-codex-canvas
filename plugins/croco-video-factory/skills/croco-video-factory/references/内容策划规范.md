## 目标与阶段边界

把一个通识或科学主题策划成准确、适龄、视觉先行的视频脚本初稿。

本阶段只负责事实策划、主题选择、叙事结构和临时视觉节拍。不得在本阶段确定最终配音时长、分镜分组、镜头语言、转场、角色参考绑定或生成提示词。

依次输出以下四个文件：

1. `事实依据.md`
2. `主题分析.md`
3. `内容大纲.md`
4. `视频脚本-初稿.md`

## 输入

- Topic：单一知识主题。
- 目标用户：明确年龄段或一般受众。
- 内容方向：本片要解决的问题或教育目标。
- Main Characters：用户指定的正式角色及人设。
- User-defined NPCs：用户指定或允许创建的配角。
- Optional Visual Style：可选视觉风格。
- `maxDurationSeconds`：项目允许的最长成片时长；缺省按约 90 秒策划，且不得超过 120 秒。

不得自动选择用户未指定的正式角色。角色的既有人设、口头习惯和能力边界优先于通用表达建议。

## 一、事实依据

先研究，再写钩子和故事。不得凭模型记忆补齐关键事实。

在 `事实依据.md` 中逐条记录：

- 可进入脚本的事实或专业概念。
- 对应来源名称与可访问链接。
- 来源支持的准确表述。
- 适合目标用户的通俗解释。
- 必须保留的限定词、适用范围或争议。
- 该事实可能服务的钩子、正文或结论。

优先使用权威机构、原始研究、教材或可靠专业资料。惊人数字、纪录、概率、历史第一和因果结论必须有直接来源；无法验证时，不得把它写成钩子或确定性陈述。

## 二、主题分析

在 `主题分析.md` 中先展开候选，再做选择：

- 一句话核心问题。
- 看完后只记住的一句话。
- 目标用户已有认知与理解门槛。
- 最值得纠正的误解。
- 本片覆盖边界与明确不讲的内容。
- 至少 3 个钩子候选。
- 至少 2 条叙事路线候选。

逐项评价钩子与叙事路线：

- 事实可信度。
- 与核心问题的相关性。
- 前 3 秒的视觉可见性。
- 目标用户是否容易理解。
- 是否能自然兑现，而非标题党。

选择一个主钩子和一条主叙事路线，并说明淘汰其他候选的原因。不要把没有事实支撑的夸张感当成吸引力。

## 三、内容大纲

在 `内容大纲.md` 中把叙事路线拆成连续节拍。每个节拍必须包含：

- 知识目的：这一段只让观众理解一件事。
- 叙事事件：角色正在做什么或发现什么。
- 角色功能：提问、误解、演示、解释、验证或总结。
- 观众收获：这一段结束后新增的理解。
- 视觉隐喻或可见证据。
- 临时时间预算。
- 与前后节拍的依赖关系。

至少安排一次认知转折，例如误解被纠正、实验结果揭晓、表象与原理反转。每个节拍都必须推进理解；纯气氛、重复解释和无功能笑料应删除。

## 四、视频脚本初稿

先设计可见事件，再匹配旁白和对话。不得先写完整口播再寻找装饰画面。

`视频脚本-初稿.md` 只保留可供审核和后续制作使用的正文，包含：

1. 暂定标题与一句话承诺。
2. 目标用户、核心概念、核心类比和临时总时长。
3. 角色及其本片功能。
4. 脚本节拍表。
5. 启发式结尾。

脚本节拍表使用以下字段：

| 节拍 | 知识目的 | 临时时长 | 视觉事件与动作 | 旁白/对话 | 画面文字 | 叙事衔接 |
|---|---|---:|---|---|---|---|

`画面文字` 默认填“无”。只有用户明确要求画面内显示具体文字时，才写入精确原文并标记为“用户明确要求的画面文字”；不得为科普关键词、数字、标签、对白或旁白自行新增画面文字。

“叙事衔接”只写 `继续`、`对比`、`转折`、`时间推进` 或 `收束`，不得指定硬切、叠化、运镜或其他制作方案。

## 表达规则

- 一句话只承载一个主要意思，短而自然；不设置固定字数上限。
- 不得为了缩短句子删掉专业名词、事实限定或因果条件。内容过密时拆分节拍。
- 专业名词必须准确出现，并立即用可见现象、生活经验或简短类比解释。
- 不使用“宝子们、家人们、绝绝子”等成人网络梗。
- 不强行使用“嘿小伙伴们”、拟声词、语气词或卖萌表达。
- 不采用居高临下的讲课口吻，也不把角色写成只会站着讲解的主持人。

按受众调整语言：

- 6–8 岁：具体词汇、适度重复、短句和轻量语气词。
- 9–12 岁：活泼自然，但不刻意幼态化。
- 12–15 岁：直接、尊重、准确；有趣但不装可爱。
- 一般受众：自然、清楚、克制。

## 结尾与交接

禁止点赞、关注、转发、评论、购买、订阅等社交或营销 CTA。结尾应兑现开场问题，可用认知回扣、可验证的小结或开放思考留下余韵。

P2 内完成事实与表达审核，并从初稿生成 `视频脚本.md`。如果审核删除或实质改变了钩子、大纲或结论依赖的事实，必须在 P2 更新受影响的四个上游文件后再继续。

## 自检

- [ ] 每个关键事实都有来源和准确边界。
- [ ] 钩子承诺能在正文中兑现。
- [ ] 全片只围绕一个核心问题。
- [ ] 每个节拍只有一个主要知识目的。
- [ ] 视觉事件本身推进理解，而非装饰旁白。
- [ ] 专业名词准确，并得到即时解释。
- [ ] 语言符合目标年龄和角色设定。
- [ ] 没有提前决定 P4 的真实时间线、P5 的镜头设计或 P7/P8 的 H3 生成内容。
- [ ] 没有社交或营销 CTA。
