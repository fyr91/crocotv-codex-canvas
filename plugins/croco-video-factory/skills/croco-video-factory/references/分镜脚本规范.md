# P4 导演总纲与文字分镜规范

## 边界

P4 消费 P2 锁定剧本和 P3 已验收角色/Variation/Voice/场景/道具资产，锁定拍摄相关创作判断。它不重复角色四视图或场景生产设计，不生成 Storyboard 图片、Storyboard Prompt、H3 Prompt、语音或音乐。

主要单位是 Storyboard Unit/正式文字分镜，不按场景分列，也不叫“镜头设计卡”。一个分镜可以跨不同场景；每个分镜是一份完整导演文字设计，可在 P5 中再表现为多个 Storyboard 画格。

Gemini 使用 [P4 导演策划 System Prompt](P4-导演策划-System-Prompt.md)完成一次阶段任务；上下文过长时可按连续批次运行，但共享同一导演总纲和输入快照。全部草案形成后，GLM 使用 [P4 跨分镜审核 System Prompt](P4-跨分镜审核-System-Prompt.md)只总审一次。

## 全片导演总纲

只定义与导演拍摄相关的共同规则：

- 观看关系、叙事视角、信息揭示策略和情绪弧；
- 视觉风格、色彩、光线、材质和画幅/构图原则；
- 景别、角度、焦段倾向、机位高度、景深和运镜语法；
- 全片节奏、信息密度、留白、表演、动作和反应原则；
- 人物动效、物理反馈、环境动效和转场边界；
- 音乐、环境音、音效、对白/旁白与画面节拍的整体关系。

不要为每个分镜重复公共规则；分镜只记录该单元的具体应用或有理由的偏离。

## 剧本覆盖与拆分

逐 `beatId` 建立覆盖表。每个正式分镜先确定：

1. 对应的完整剧本片段、Narration、Dialogue 和用户指定画面文字；
2. 观众此刻必须注意/理解什么；
3. 单元结束时信息、动作、空间或角色状态发生什么变化；
4. 为什么需要形成独立分镜，而不是留在前一单元。

只有新单元带来新的知识目的、可见证据、动作状态、空间/时间变化、视角作用或叙事转折时才拆分；没有新增信息/状态的重复角度应合并。拆并不得改变事实、台词、事件顺序或因果。

## 每个文字分镜的固定内容

每个 `shotId` 至少记录：

- `shotOrder`、预估生成时长、时长依据、`storySegmentId`、有序 `sceneIds`；
- 对应剧本原文、知识/叙事目的、起始状态、结束状态和必须可见的证据；
- 场景空间组织、角色/Variation/状态、服装、持物和小型道具；
- 情绪、信息密度、节奏、留白和注意力变化；
- 人物表演、动作顺序、反应、视线、受力和人物动效；
- 关键画面方向：视觉重心、前中后景、空间关系、必须出现/禁止出现内容；
- 景别、角度、机位、焦段意图、景深、构图、运镜和转场关系；
- 环境动效、光影/粒子/天气/物理反馈；
- 音乐功能、环境音、音效、Narration/Dialogue 边界和表演声音方向；
- 后续 Storyboard/H3 的不可违反约束、引用资产和风险。

“关键画面方向”是文字锚点，不是正式出图或关键帧。

## 预估生成时长

P4 不生成音频测时。每个 `shotId` 直接按锁定剧本文字和表演规划估算：

1. 按角色、语速和语气预估对白/旁白占用时间；
2. 补入无法与语言同时完成的动作、反应和运镜时间；
3. 增加必要的前置建立与结束留白；
4. 对总值向上取整，得到 3–15 秒整数的 `预估生成时长`。

该数值只是 P6/P8 的初始目标参数，不叫“最终视频时长”。若一个 P4 分镜无法在单个 15 秒片段中完整承载，不改变其 `shotId`、剧本覆盖、事件顺序和导演意图，只标记 P6 需要生成片段化。P6 拆分优先级固定为：场景切换处 → 本来不连续的画面/动作边界 → 其他自然停顿；前两类片段默认 `independent` 或 `soft-continuity`。非必要不拆连续动作；只有不存在安全断点时才使用 `tail-frame`。

## 连续性

相邻分镜核对角色位置、朝向、视线、屏幕运动、进出路线、双手/持物、服装状态、场景锚点、光向、动作阶段和声音衔接。连续性类型：

- `independent`：场景/时间断开或无需继承具体画面，可并行。
- `soft-continuity`：复用场景或风格但允许重新构图，不等待前镜。
- `tail-frame`：动作、运镜、变形或连续镜头跨单元延续；填写 `dependsOnShotId`、`reason`、`inherit`，等待前镜尾帧。

因 H3 时长限制且无法避开的同一连续动作/运镜拆分必须使用 `tail-frame`，不得降级。场景切换处或本来不连续的画面边界应优先拆成无特定依赖的生成片段；跨场景但刻意保持连续运动时，仍需明确切换时间点、过渡机制和继承状态。

## 资产绑定与可见文字

绑定 P3 稳定资源 ID：角色四视图/Variation、场景综合设定图、道具和 Voice。参考图只锁定身份、比例、服装、材质、空间、光线和道具锚点，不复制参考板排版、背景、技术标记或 Storyboard 风格。

画面文字默认无。只有用户明确要求的精确原文可进入分镜，且不得把旁白、对白、知识点、数字或参考图文字自动转成屏幕文字。

## GLM 跨分镜总审与回修

总审检查：剧本/Claim 覆盖、遗漏/重复、预估生成时长是否能承载语言/动作/留白、资产引用、角色/场景/道具、动作/状态、视线/运动/持物、空间/光线、镜头方向、情绪/节奏、声音和依赖链。总审不把预估值宣称为最终成片时长。

GLM 输出总体结论和按 `shotId` 定位的问题，不直接改写分镜正文。受影响分镜将“当前 Result + 审核 Result + 已接受人工反馈”作为新输入重跑 Gemini；改变剧本时退回 P2，改变生产资产时退回 P3。
