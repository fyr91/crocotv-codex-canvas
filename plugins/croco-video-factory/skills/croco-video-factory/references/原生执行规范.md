# Skill 原生阶段执行适配器

## 适配器边界

本文件只实施[固定 P1–P10 制作流程](执行后端选择规范.md)，不定义另一套阶段、产物、门禁或失效规则。`Projects/` 项目目录及其 Markdown、JSON、媒体和运行状态是唯一事实来源；不得为了展示进度建立不参与真实执行的 Canvas 图。

运行捆绑脚本前，将工作目录设为 CrocoTV 仓库根目录。脚本从 `CROCO_ENV_FILE`（默认 `.codex/.env`）解析共享环境，从当前仓库解析 `characters/`、`Projects/` 和默认输出，并使用当前 Plugin 内 Skill 目录中的脚本路径。脚本只能完成当前阶段，不得跳过共同门禁。

## P1 需求与项目

使用 `pull-latest-characters` 同步角色并报告版本、`added`、`updated`、`unchanged` 和 `assetsDownloaded`；鉴权、下载、大小或 SHA-256 校验失败时停止。输入全部确认后按[项目初始化规范](项目初始化规范.md)运行 `scripts/公共/创建视频项目.mjs`，将创作简报、正式角色、Voice ID 和后端选择写入唯一项目状态。

## P2 事实与脚本

按[内容策划规范](内容策划规范.md)和[通识教育视频节奏规范](通识教育视频节奏规范.md)执行原生文字模型调用，依次保存 `事实依据.md`、`主题分析.md`、`内容大纲.md` 和 `视频脚本-初稿.md`。使用 `content-optimization-audit` 产出 `视频脚本.md`；审核改变关键事实或结构时同步上游文件。

## P3 角色与视觉设定

按 NPC、三视图、三视图验收和故事场景规范，按需运行 `scripts/策划/生成NPC三视图.mjs`、`生成场景设计图.mjs`、`记录图像验收.mjs` 和 `记录场景设计验收.mjs`。每项最多生成五次并选择最佳可用结果；只有已验收资源可进入下游。

## P4 配音与真实时间线

按[情景化语音任务规范](情景化语音任务规范.md)，使用 `character-speaking` 和 P1 确认的最新 Voice ID 生成语音。外层并行，单条任务内部顺序执行；运行 `scripts/公共/角色与时长.mjs` 或等价原生步骤读取实际音频时长并重算时间线，不得用文字估算代替真实媒体时长。

## P5 分镜与 Storyboard

按[分镜脚本规范](分镜脚本规范.md)、[Storyboard 基础提示词](Storyboard基础提示词.md)和[Storyboard 验收规范](Storyboard验收规范.md)保存 `storySegmentId`、`sceneId` 及 `independent` / `soft-continuity` / `tail-frame` 关系。运行 `scripts/策划/生成分镜图.mjs --shot-dir <分镜组目录>` 和适用的验收脚本；每组最多五次。P5 通过后只能进入 P6。

## P6 Pre-roll 确认

按[Pre-roll 确认规范](Pre-roll确认规范.md)在当前项目 `Pre-roll/` 中保存该阶段的中间产物、来源快照、当前视频指针、哈希和确认记录；旧版本移入 `Pre-roll/历史版本/`。复用公共 H3 Prompt/视频能力生成隔离预演，不另建正式项目，不把预览状态写入正式分镜。展示实际视频并等待确认；反馈回写到最早受影响的 P2–P6 产物后重生。

## P7 H3 Prompt

先验证 P6 当前 Pre-roll 确认快照有效。按[H3 视频生成规范](H3视频生成规范.md)读取与 H3 模式一致的静态 System Prompt，使用 `minimax-video-prompt-optimizer` 维护提示词规范，运行 `scripts/视频/生成H3提示词.mjs --shot-dir <分镜组目录>`。模型只生成基础 Prompt；脚本按真实文件顺序确定性追加 audio references、素材哈希、已确认的全片调整和输入快照。

## P8 H3 视频

运行 `scripts/视频/生成H3分镜视频.mjs`。依赖链内部串行，独立链在并发上限内并行；上游失败时阻塞后镜。场景、音频、Prompt、System Prompt 或尾帧哈希变化时使旧结果失效。

## P9 验收与定向重做

运行 `scripts/音频/火山ASR.mjs`、`scripts/音频/验收H3对白.mjs` 和 `scripts/视频/验收H3视觉.mjs` 的适用入口。实际检查每段首、中、尾帧以及连续镜头对；失败时只回到受影响阶段并重做依赖链，完成后重新执行 P9。

## P10 安全合片与交付

只有当前对白与视觉验收均为 `pass` 且输入快照有效时，才运行 `scripts/视频/合并H3分镜视频.mjs --project <项目目录>`。验证源哈希、原生 Profile、完整解码和拼接前后 PCM 哈希后，原子发布 `成片/完整视频.mp4`。
