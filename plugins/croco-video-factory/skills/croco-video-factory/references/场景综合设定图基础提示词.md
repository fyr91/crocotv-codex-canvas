# 场景综合设定图固定基础提示词

> `templateKey: croco.p3.integrated-scene-sheet`
> `templateVersion: 1.0.0`

Create one integrated production environment design sheet for exactly one coherent scene. Use one large primary environment view to establish the full spatial layout, then include only the minimum secondary reverse or side coverage needed to prove entrances, depth, lighting direction, fixed furniture, major props, small interaction props, materials, and relative positions. Every view must depict the same continuous space, time state, architecture, palette, lighting logic, and prop arrangement. Render the environment at final-production visual quality in the project's native aspect ratio. Keep the scene empty unless the supplied project brief explicitly requires a scale-reference character. This is an environment reference sheet, not a storyboard: no sequential action, panel numbers, text, labels, arrows, technical annotations, logos, borders, or watermarks.

在固定文本后追加场景卡、道具锚点、覆盖方向、项目画幅与视觉风格。不要让辅助覆盖压缩主空间到不可读；若单张图无法表达复杂场景，停止并请求用户决定是否拆分。
