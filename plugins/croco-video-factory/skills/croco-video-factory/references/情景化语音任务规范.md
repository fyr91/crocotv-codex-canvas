# 正式 Speech 按需执行规范

## 启用条件

当前 P1–P8 只在 P3 锁定 Voice ID/参考音色/Voice Prompt，不默认生成正式语音。只有用户或后续共享流程明确启用 Speech 阶段时才加载本规范；不得把它重新塞回 P4 或让 DeepSeek 参与通用策划。

## 情景化任务

从锁定剧本、P4 表演/声音方向和角色设定，为每条原始台词生成简洁、可表演的 `direction`：只写情绪、节奏、停顿、重音、音量和表达目的。不得补剧情/动机、加入镜头/后期/克隆指令或改变台词任一字符。

```json
{
  "shot": "正式 shotId",
  "content": "锁定剧本的原始旁白或对白，逐字符不变",
  "direction": "情景化表演指导"
}
```

调用 `character-speaking` 时使用当前 Voice ID。DeepSeek V4 Flash GA 正式版（`deepseek-v4-flash-ga-260731`）以 `thinking.enabled` 只执行逐字保真的语气分段，再交给 Seed-TTS；输出后做字符级核验，失败按既有策略重试。真实音频时长与 P4/P6 假设冲突时，回流受影响文字分镜和 H3 Prompt，不静默加速、裁剪或改台词。

同一角色相邻台词的表演状态应自然衔接；参考音频始终保留完整文件和来源哈希。
