# 情景化语音任务规范

## 目标

结合角色设定和台词所在情景，为每条台词生成一个可执行的情景化 `direction`，交给 `character-speaking`。

## 生成规则

- 从最终脚本、内容大纲和角色资料理解台词所在情景，但不输出或记录分析过程。
- `direction` 只保留该情景下必要的情绪、节奏、停顿、重音、音量和表达目的。
- 指令应简洁、具体、可表演，避免只写“自然一点”“有感情”等通用描述。
- 不补写脚本未支持的剧情或动机，不加入镜头、画面、后期和音色克隆指令。
- 不改变原台词的任何字符。

## `语音任务.json`

每个任务只保留 `shot`、`content` 和 `direction`：

```json
{
  "shot": "分镜编号与名称",
  "content": "原始旁白或对白，逐字符不变",
  "direction": "交给 character-speaking 的情景化表演指令"
}
```

`content` 只能来自最终 `视频脚本.md`。调用 `character-speaking` 时，把 `content` 作为台词，把 `direction` 作为表演指导。

## 检查

- `direction` 符合角色设定和台词所在情景。
- 没有改变台词、事实立场或剧情设定。
- 同一角色相邻台词的表演状态能够自然衔接。
