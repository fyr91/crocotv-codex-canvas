# 固定制作流程与执行后端规范

## 权威边界

本文件是 Croco Video Factory 阶段顺序、阶段目标、共同产物、门禁和失效规则的唯一权威。领域规范说明某个阶段如何达标；原生与 Canvas MCP 文档只说明同一阶段如何实施。它们都不得新增、删除、重排或重新解释阶段。

生产控制和执行后端都是流程参数，不是流程分支：

- Auto / 互动只决定是否在可选门禁暂停。
- 本地 Canvas / Skill 原生只决定阶段如何执行和保存状态。
- Topic、阶段契约、审核标准、依赖失效与交付条件不因模式改变。

## 首轮交互

第一轮同时确认生产控制（Auto / 互动）与执行后端（本地 Canvas / Skill 原生）。两项未确定前不得询问 Topic、角色或视觉风格，也不得创建项目或启动第三方调用。确定后从 P1 开始，不为四种组合分别规划流程。

## P1–P10 唯一阶段定义

| 阶段 | 固定工作 | 固定产物与进入条件 |
|---|---|---|
| P1 需求与项目 | 确认 Topic、目标用户、内容方向、正式角色、临时 NPC 和可选视觉风格，同步角色 | 唯一项目状态、创作简报、正式角色与 Voice ID；Topic、目标用户、内容方向和正式角色未确认时停止 |
| P2 事实与脚本 | 事实核验、主题分析、内容大纲、视觉先行初稿与内容审核 | 事实依据、主题分析、内容大纲、最终视频脚本；互动门禁一 |
| P3 角色与视觉设定 | 正式角色素材、NPC、三视图、场景设计与图像验收 | 已验收角色、场景资源和稳定资源标识；互动门禁二 |
| P4 配音与真实时间线 | 语气优化、角色语音、读取真实音频时长与重算时间线 | 每段音频、Voice ID、实际时长和时间线；不单独暂停 |
| P5 分镜与 Storyboard | 分镜脚本、故事/场景分组、连续性依赖、Storyboard 生成与验收 | 3–15 秒分镜、已验收 Storyboard、`storySegmentId`、`sceneId` 和连续性关系；互动门禁三 |
| P6 Pre-roll 确认 | 提取完整故事线核心点，抽取多个 Storyboard 的相关元素，重建短场景脚本与风格，生成 3–10 秒真实预演 | 核心故事点、Storyboard 抽取清单、Pre-roll 场景脚本、风格定义、实际视频、来源快照和用户确认/调整；所有模式强制暂停 |
| P7 H3 Prompt | 选择与 H3 模式一致的受管理 System Prompt，组合最终文字、图像和音频 | 基础与最终 H3 Prompt、有序素材清单、哈希和输入快照 |
| P8 H3 视频 | 按分镜依赖图执行 MiniMax H3 | 分镜视频；独立链并发，`tail-frame` 链串行，前镜失败则后镜阻塞 |
| P9 验收与定向重做 | 火山 ASR、首中尾帧视觉、角色/场景/跨镜连续性检查 | 当前 ASR 与视觉 PASS；失败时只重做受影响节点和依赖链 |
| P10 安全合片与交付 | 校验快照、源文件、解码和音频后按序合并 | 最终视频与可追溯合片记录；任何过期或未通过分镜都禁止合片 |

## 门禁与失效

- 互动模式只在 P2、P3 和 P5 完成后追加可选暂停；Auto 模式自动继续。
- P6 是独立同级阶段和所有模式的强制人工确认门禁。确认前不得创建或运行 P7–P10 正式任务。
- P6 收到调整时，把反馈回写到最早受影响的 P2–P6 权威产物，重新通过相应门禁并再次确认 Pre-roll。
- 任何输入内容、资源、顺序、System Prompt、音频时长、场景或前镜尾帧变化时，只使受影响的下游产物和依赖链失效。
- 不得提前生成下游产物伪装进度，不得把未验收或已过期素材带入下一阶段。

## 后端适配契约

- [Skill 原生阶段执行适配器](原生执行规范.md)使用 `Projects/` 目录、结构化文件、媒体、子 Skill 与捆绑脚本作为唯一事实来源。
- [Canvas MCP 阶段执行适配器](Canvas-MCP执行规范.md)使用 Canvas 项目、节点、连接、任务、资源与 Comment 作为唯一事实来源。

两个适配器必须消费同一阶段输入并产出语义相同的结果。实施机制不同不构成删减共同产物、审核门禁或追溯信息的理由。

## 状态边界与禁止降级

Canvas 后端指定 canvasId 或当前画布时先读取并复用；未指定时在 P1 输入确认后创建，使用新 `factoryRunId` 隔离本次生产，不得清空已有内容。原生后端在 P1 创建唯一 `Projects/` 项目，不得建立不参与真实执行的 Canvas 假流程。

没有用户明确同意，不得在 Canvas 与原生之间切换、混用、同阶段维护两套事实来源，或把一边结果静默复制到另一边并声称完整复现。获准切换时，先交付当前阶段、有效产物、失效项和未完成依赖，再从同一 P 阶段继续。
