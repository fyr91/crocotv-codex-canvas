# 故事场景设计规范

## 目标

在 Storyboard 之前固定每个故事片段的空间、灯光、色彩、材质和道具锚点。同一故事片段被 H3 时长拆成多个 clip 时，后续 clip 必须继承同一组场景设计图，并对前一 clip 建立 `tail-frame` 依赖。

## 场景与故事分组

编写 `场景/场景计划.json`，其中 `aspectRatio` 必须与项目 `分镜计划.json` 一致。先用 `storySegmentId` 划分连续故事，再用 `sceneId` 标识固定空间。场景相同但时间跳跃或独立叙事时可使用不同 `storySegmentId`；因 15 秒限制而拆开的同一段对话、动作或运镜必须使用相同 `storySegmentId` 和 `sceneId`。场景设计图必须原生使用项目画幅构图；竖屏项目不得先设计横屏空间再裁切。

```json
{
  "schemaVersion": 1,
  "aspectRatio": "9:16",
  "scenes": [
    {
      "sceneId": "S01",
      "folder": "S01-明亮饭桌",
      "storySegmentIds": ["G02"],
      "invariants": ["圆木饭桌", "落地窗在人物后方", "白天中性自然光", "固定餐具与绿植"],
      "views": ["01-桌对面主视角", "02-桌右侧反向视角"]
    }
  ]
}
```

## 设计图结构与生成

每个场景至少设计一个视图；镜头会大幅反打、横移或暴露新空间时，增加能覆盖该方向的辅助视图。

```text
场景/S01-明亮饭桌/
├── 场景卡.md
└── 视图/
    ├── 01-桌对面主视角/
    │   ├── 场景设计提示词.md
    │   ├── 输入参考图.json
    │   └── 当前场景设计图.json
    └── 02-桌右侧反向视角/
```

`场景设计提示词.md` 必须明确建筑结构、空间尺度、项目画幅的安全构图区、镜头方向、光源方位、色彩、材质、固定家具/道具及它们的相对位置。设计图是最终成片质感的空场景，不是黑白 Storyboard；默认不放入角色，不得出现文字、Logo、箭头、批注或分格。

```bash
node <skill>/scripts/策划/生成场景设计图.mjs --view-dir <场景视图目录>
node <skill>/scripts/策划/记录场景设计验收.mjs --view-dir <场景视图目录> --attempt 1 --record pass --reviewer codex --checks spatial-layout,lighting-palette,materials-props,camera-coverage,clean-no-text
```

同一视图最多生成五次。只有 `当前场景设计图.json.status = pass` 的图片可进入 Storyboard 和 H3。

## 分镜绑定

`分镜计划.json` 的每个非合成分镜必须写入 `storySegmentId`、`sceneId` 和 `sceneDesignRequired: true`。每个分镜目录创建 `场景参考图.json`，按实际上传顺序绑定已验收场景视图：

```json
{
  "sceneId": "S01",
  "storySegmentId": "G02",
  "references": [
    {
      "path": "../../场景/S01-明亮饭桌/视图/01-桌对面主视角/场景设计图-第01次.png",
      "view": "桌对面主视角",
      "purpose": "锁定空间布局、窗景、光向、桌面道具与成片材质",
      "imageSha256": "<accepted image sha256>"
    }
  ]
}
```

Storyboard 生图和 H3 Ref2VA 必须使用同一份 `场景参考图.json`。角色参考只锁定角色，场景参考只锁定环境，不得相互替代。

## 依赖硬规则

相邻两个分镜的 `storySegmentId` 和 `sceneId` 都相同时，后一分镜必须使用 `tail-frame`，`dependsOnShotId` 必须指向前一分镜，`inherit` 至少包含 `scene`、`characterPosition`、`wardrobe`、`lighting` 和 `props`。这种拆分不得使用 `independent` 或不等待前镜的 `soft-continuity`。

同一 `sceneId` 但 `storySegmentId` 不同时，可使用 `soft-continuity`，但仍必须复用场景设计图。纯黑、程序化图形或用户明确要求的其他合成画面可设置 `sceneDesignRequired: false`，并写明原因。
