# 通识教育视频节奏规范

## 适用范围

本规范只约束 P2 的内容节奏与临时时间预算。P4 根据最终脚本和实际配音重算时间线，P5 决定最终分镜、运镜和转场。

默认成片约 90 秒；以项目 `maxDurationSeconds` 为上限，且不得超过 120 秒。一个视频只解决一个核心问题。

## 注意力曲线

### 1. 钩子：前 3 秒

开场立即展示值得追下去的现象或问题，不先寒暄、报幕或介绍背景。

可用钩子：

- 反常视觉：先出现不符合直觉的结果。
- 大胆提问：提出目标用户能立刻理解的问题。
- 误解对比：并列“看起来如此”与“其实如此”。
- 实验预告：先展示即将验证的关键动作。
- 已验证事实：用可追溯事实制造尺度感。

钩子不得依赖无来源数字、恐吓、伪悬念或正文无法兑现的夸张承诺。

### 2. 建立问题

尽快让角色遇到一个具体阻碍、误解或观察结果。背景只保留理解问题所必需的信息。

### 3. 发展理解

按“现象 → 尝试 → 解释 → 验证”或同等清晰的因果顺序推进。每个节拍只承担一个知识目的，并让画面发生可见变化。

### 4. 中段转折

全片至少出现一次认知变化：

- 常见误解被证据纠正。
- 实验或推理结果揭晓。
- 视觉类比从表象转向原理。
- 角色用新理解解决先前问题。

转折必须来自知识内容，不靠突然音效或无关笑料冒充高潮。

### 5. 回扣与余韵

结尾回答开场问题，回收核心视觉或类比，并留下一个可继续观察的角度。不得加入点赞、关注、评论、购买、订阅等 CTA。

## 节拍时长

- P2 的单个临时视觉节拍通常为 3–12 秒。
- 简单揭示、反应或对比可短；概念演示和因果解释可长。
- 不要机械地把所有节拍写成相同时长。
- 同一静态构图持续过久时，应改变动作、信息层级或观察角度。
- 口播内容过密时，优先拆分节拍，不通过删减事实条件强塞时长。

这些数字只用于内容可行性检查，不是最终分镜时长。不得根据中文字符数或英文词数公式锁定口播时长。

## 视觉节奏

画面变化必须服务理解。可以交替使用：

- 角色行动与结果反应。
- 现实尺度与放大后的机制。
- 整体结构与局部细节。
- 错误预测与实际结果。
- 抽象概念与生活类比。

连续节拍之间至少改变一个有意义的变量：动作、信息、尺度、位置、时间或因果状态。仅换背景、颜色或装饰不算有效推进。

画面文字默认写“无”。只有用户明确要求画面内显示具体文字时，才保留其精确文字并标记为“用户明确要求的画面文字”；不得自行把关键词、数字、标签、知识点或口播转成画面文字。

## P4 时间重算

获得最终脚本和实际语音后：

1. 以真实音频时长为准重算完整时间线。
2. 给必要的动作和理解反应留出呼吸空间。
3. 配音溢出时拆分或重新分配节拍，不添加或改变事实。
4. 不为了保留 P2 的临时时长而加速到难以理解。
5. 把最终镜头组控制在主流程规定的 3–15 秒范围。

## 常见反模式

- 开场寒暄后才进入问题。
- 用惊人数字替代真实的知识冲突。
- 每个节拍等长，形成机械节奏。
- 旁白持续解释，画面只作装饰。
- 一个节拍同时引入多个新概念。
- 中段没有验证、纠错或认知变化。
- 专业词出现后很久才解释。
- 为了“更可爱”牺牲准确与自然。
- P2 提前指定转场、运镜或生成提示词。
- 结尾重复全文，或加入社交和营销引导。
