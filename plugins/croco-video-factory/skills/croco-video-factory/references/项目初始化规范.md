# P1 项目初始化规范

## 必填输入

- `topic`、`targetAudience`、`contentDirection`；
- 目标时长、原生画幅和发布环境；
- 用户指定的 `mainCharacters` 与 `userDefinedNpcs`；
- Auto/互动与 Canvas/Skill 原生。

正式角色只保留用户指定项，不得自动选择。缺少叙事角色时只记录待设计 NPC 需求，不在 P1 生成角色。可选输入包括已有角色/Voice/场景/品牌/风格参考、视觉偏好、禁区、不可改变条件和允许模型补全的范围。

## 固定产物

1. 项目简报：目标、受众、范围、时长、画幅、发布环境和成功标准。
2. 资源索引：已有角色、Voice、图片、场景、品牌和可复用资产的稳定标识。
3. 用户硬约束与禁用项。
4. 缺失项、冲突项和待用户决定项。

P1 只做确定性收集、结构化与完整性检查，不调用外部 LLM，不编剧、不做导演设计、不生成媒体。

原生目录为 `Projects/YYYYMMDDTHHmmss-中文主题`，中文目录、JSON camelCase。Canvas 只在输入确认后创建/读取项目并写入项目公共列。
